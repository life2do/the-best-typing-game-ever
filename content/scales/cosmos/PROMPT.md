# Prompt: cosmos complexity scale

Cosmos scale: from a pebble to a galaxy.

Seven steps, one per proficiency tier, each more complex than the last. The avatar model for each step is procedural (`procedural:cosmos-<tier>`): build it from simple primitives whose count and detail grow with the tier. Implement all core rig hooks (idle, move, jump, land, stumble, celebrate, powerup) with squash/stretch/spin. Provide 8 customisation slots with ranges unlocked by stars.
