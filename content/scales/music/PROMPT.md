# Prompt: music complexity scale

Music scale: from a note to a cosmic choir.

Seven steps, one per proficiency tier (note → drum → guitar → band → orchestra → stadium → cosmic choir), each more complex than the last. The avatar model for each step is procedural (`procedural:music-<tier>`): build it from simple primitives whose count and detail grow with the tier, in the theme's two customisable colours. Implement all core rig hooks (idle, move, jump, land, stumble, celebrate, powerup) with squash/stretch/spin. Provide 8 customisation slots (colours, pattern, size, accessory, trail, aura, idle style) with value ranges unlocked by stars. Kid-friendly, non-violent.
