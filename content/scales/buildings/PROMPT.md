# Prompt: buildings complexity scale

Buildings scale: from a tent to a floating city.

Seven steps, one per proficiency tier (tent → hut → house → castle → skyscraper → space station → floating city), each more complex than the last. The avatar model for each step is procedural (`procedural:buildings-<tier>`): build it from simple primitives whose count and detail grow with the tier, in the theme's two customisable colours. Implement all core rig hooks (idle, move, jump, land, stumble, celebrate, powerup) with squash/stretch/spin. Provide 8 customisation slots (colours, pattern, size, accessory, trail, aura, idle style) with value ranges unlocked by stars. Kid-friendly, non-violent.
